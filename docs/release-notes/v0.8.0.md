## Klassic 0.8.0

Klassic 0.8.0 is the release where the three native targets stop being
different languages. Every one of the 58 sample programs now compiles on
x86-64 Linux, Apple Silicon macOS, and x86-64 Windows -- the same 58, with
the same output. The arm64 backend started this cycle able to build four of
them.

Getting there meant giving the Apple Silicon backend a real garbage
collector, then the language surface that had only ever existed on x86-64,
and finally making the last stdlib module portable enough for every target
to build it.

### A garbage collector on Apple Silicon

- **The hand-written ZGC is architecture-independent (#600)** -- its 24
  runtime routines are emitted through a `PortableAsm` trait instead of
  x86-64 instructions. The x86-64 output is byte-identical across the
  refactor, which is how the port could be trusted at all.
- **Apple Silicon runs that collector (#601, #602, #603)** -- coloured
  pointers, an inline load barrier, colour-on-store, precise shadow-stack
  roots, incremental marking, region allocation, and moving evacuation, all
  live on arm64. `--gc-stress` and `--gc-poison` corpora agree with the
  evaluator under 3,464 collections, and `--gc-log` reports relocated
  objects, so compaction is doing real work rather than being skipped.
- Two AArch64-specific hazards are worth recording: `bl` overwrites `x30`,
  so a routine that calls without saving the link register can never
  return; and a 16-byte push stride makes prologue-saved registers overlap
  frame slots that an 8-byte stride would not.

### The language, on every target

The arm64 backend gained, in order: typeclasses and instance dispatch,
lambdas and `map`/`foldLeft`, collection rendering, dictionaries of lambdas,
string interpolation of collections, `matches`, list content equality,
nested lists, `null` and values that may not be there, `Map` literals with
their builtins, functions passed under a name, higher-kinded instances,
file I/O including paths that are not literals, `sleep`/`stopwatch`,
records whose layout is decided by their constructor, generic enums with
their constructors and `match`, curried definitions including recursive
ones, and `thread`.

Two of these are worth calling out because they are not backend-local:

- **`sleep` waits on a clock, not a syscall** -- Darwin does not publish
  its syscall numbers, so `nanosleep`'s could not be verified from a build
  host. It spins on `gettimeofday`, which was already verified. That costs
  the CPU it holds; a guessed syscall number would have cost correctness on
  someone else's machine.
- **`thread` runs its body after the program's own statements**, which is
  the approximation the x86-64 backend already made. Every target prints
  the same thing, which is the part of it a program can observe here.

### Three bugs that only real hardware found

Each of these built cleanly and ran correctly everywhere a Linux host can
check, and failed on the arm64 runner:

- **A missing box.** A recursive function's return type was inferred from
  its base case alone, because the recursive call had nothing to resolve to
  yet, so a "null or a value" result left its value unboxed and printing it
  dereferenced an integer. Recursion now takes its type from the
  specialisation that is already registered, and whether a join is nullable
  is decided before either branch is compiled and checked against what they
  turn out to be.
- **A frame sized from a guess.** Frame size came from counting
  declarations in the syntax, which cannot know that a fold reserves four
  slots and a map three -- so a function that mapped twice wrote over its
  own saved return address. Every slot is handed out by one function that
  remembers the high-water mark, and the prologue's reservation is patched
  once the body is compiled.
- **A root dropped by someone else.** The shadow stack is last-in-first-out,
  but a temporary's root was only released when its enclosing scope ended --
  so a helper rooting a slot inside someone else's push/pop window had its
  root dropped by their pop, leaving a dead stack slot rooted. The six
  helpers that root temporaries inside an expression now release them before
  returning.

### `std.json` compiles everywhere

- The JSON AST holds cons-style enums (`JsonValues`, `JsonMembers`) rather
  than `List<Json>`. A list of heap values built as it is walked is not
  something every native target can represent, and a type only one backend
  can express does not belong in a stdlib module's public API. The parser
  and `stringify` are the same code with a `match` per cell; `jsonCountValues`
  is provided so the common walk does not have to be written at each call
  site. **This changes the module's public type**: `case JArr(items)` now
  binds a `JsonValues`.
- Its functions are annotated, because an unannotated recursive function
  has to be compiled at each call site and a recursive one cannot be.

Two compiler bugs surfaced along the way, both in the x86-64 backend:
**mutual recursion was not recognised** (inlining turned on a body naming
*itself*, so two functions that call each other expanded until the compiler
ran out of stack), and **compile-time folding had no overall budget** (a
recursive parser applied to a literal document re-explored the same calls
for minutes). Recursion is now a cycle in the call graph, and folding has a
budget for the whole compilation -- running out is not an error, it means
the rest is compiled as code instead.

### A concurrent collector for the LLVM backend

- **The C garbage collector is genuinely concurrent (#592-#598)** --
  background marking and relocation, an N-mutator counted handshake, and
  pauses proportional to root count rather than heap size (~33µs under
  `--gc-log`). The LLVM backend allocates through it (#589, #590).

### Verification

Eighteen cross-target fixtures now build for all three targets, and CI runs
them on real arm64 and Windows hardware, comparing every line against the
evaluator. That is the only way the semantics of a Mach-O binary can be
checked at all from a Linux workstation, and it is what caught the three
bugs above.
